# Lokale Secrets

Dieses Verzeichnis darf ausschließlich lokale Laufzeit-Secrets enthalten, beispielsweise verschlüsselte Passwortablagen oder temporäre Zugangsinformationen.

Keine Secret-Datei, kein Zertifikat und kein realer Zugangswert darf versioniert werden. Nur diese Dokumentation und die `.gitignore` gehören ins Repository.
