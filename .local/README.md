# Lokale Arbeitsdaten

Dieses Verzeichnis ist für ausschließlich lokale, nicht reproduzierbare Arbeitsdaten vorgesehen. Dazu zählen hostabhängige Konfigurationen, temporäre Downloads und andere maschinenspezifische Hilfsdaten.

Inhalte dürfen nicht versioniert werden. Nur diese Dokumentation und die `.gitignore` gehören ins Repository.
